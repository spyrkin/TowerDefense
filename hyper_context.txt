~~~docs\decisions\0001-game-loop.cmake

# ADR 0001: Game Loop и Фиксированный Шаг Симуляции

## Статус
Принято (Updated)

## Контекст
Необходимо обеспечить детерминированность игровой физики и логики (движение монстров, расчет урона, коллизии) независимо от частоты рендера WPF и просадок FPS.

## Решение
- **Фиксированный шаг (Fixed Timestep):** Симуляция обновляется с жестко заданным шагом `fixedDeltaTime = 1/75` секунды.
- **Рендер:** Привязывается к `WPF CompositionTarget.Rendering` (Variable Timestep). Рендер отрисовывает состояния, интерполируя их между шагами симуляции для плавности.
- **Аккумулятор времени:** Используется аккумулятор (`accumulator += deltaTime`). Симуляция выполняет шаг, только если `accumulator >= fixedDeltaTime`, вычитая `fixedDeltaTime` из аккумулятора.
- **Защита от Spiral of Death (Fallback: Clamp & Drop):**
  - Максимальное число догоняющих шагов за один тик рендера: `5`.
  - Если `accumulator` превышает `5 * fixedDeltaTime`, он жестко обрезается (clamp) до этого максимального значения. Излишек реального времени отбрасывается (drop).
  - *Следствие:* При критических просадках FPS симуляция не успевает за реальным временем (эффект slow-motion), но сохраняется абсолютная стабильность физики и гарантируется отсутствие багов коллизий.
- **Изоляция:** Игровая логика (Domain/Simulation) строго изолирована от частоты рендера и не содержит ссылок на UI-таймеры или WPF-компоненты.
~~~

~~~docs\decisions\0002-mechanics-status-contracts.cmake
# ADR 0002: Mechanics/status contracts

## Статус

Принято

## Контекст

Для перехода к `N6 Simulation engine` необходимо однозначно зафиксировать правила:

- урона;
- брони;
- игнора брони;
- бронебойности;
- замедления;
- сопротивления замедлению;
- летающих целей;
- площадного урона;
- статусов;
- времени действия эффектов.

## Решение

### 1. Модель урона

Принята `Flat Reduction Model`.

Формула:

```text
EffectiveArmor = Floor(MonsterType.Armor * (1 - TowerLevelDefinition.ArmorIgnorePercent))
FinalDamage = Max(1, TowerLevelDefinition.Damage - EffectiveArmor)
```

Итоговый урон всегда не меньше `1`.

### 2. ArmorIgnorePercent

`ArmorIgnorePercent` трактуется как доля и ограничивается диапазоном:

```text
[0.0, 1.0]
```

Правила:

```text
ArmorIgnorePercent < 0.0 -> 0.0
ArmorIgnorePercent > 1.0 -> 1.0
```

При `ArmorIgnorePercent = 1.0` броня игнорируется полностью, но минимальный урон все равно равен `1`.

### 3. ArmorPiercing

`TowerKind.ArmorPiercing` является семантическим типом башни.

Механика бронебойности реализуется только через:

```text
TowerLevelDefinition.ArmorIgnorePercent
```

Отдельная формула для `TowerKind.ArmorPiercing` не вводится.

### 4. Splash / площадной урон

Если:

```text
TowerLevelDefinition.SplashRadius > 0
```

то урон получают все монстры в радиусе `SplashRadius` от точки попадания.

Правила:

```text
- урон рассчитывается индивидуально для каждого монстра;
- броня и ArmorIgnorePercent применяются к каждому монстру отдельно;
- затухание урона по расстоянию отсутствует;
- splash-урон не наносит урон башням и базе;
- SplashRadius <= 0 означает отсутствие площадного урона.
```

Конкретная механика выбора целей и обработки попадания реализуется в `N6 Simulation engine`.

### 5. Летающие цели

`MonsterClass.Flying` означает воздушную цель.

Вводится флаг:

```csharp
public bool CanTargetFlying { get; init; } = true;
```

в `TowerType`.

Правило:

```text
Если MonsterType.Class == Flying,
башня может атаковать этого монстра только если TowerType.CanTargetFlying == true.
```

Значение по умолчанию:

```text
true
```

Это сохраняет обратную совместимость и позволяет позже точечно отключать атаку воздушных целей у отдельных башен.

### 6. Замедление

Замедление применяется, если:

```text
TowerLevelDefinition.SlowPercent > 0
```

Независимо от `TowerKind`.

Значения:

```text
SlowPercent
SlowResistance
```

трактуются как доли в диапазоне:

```text
[0.0, 1.0]
```

Например:

```text
0.25 = 25%
0.70 = 70%
```

Формула применения:

```text
effectivePercent = basePercent * (1 - SlowResistance)
effectivePercent = min(effectivePercent, MechanicsLimits.MaxSlowPercent)
```

Правило стакинга:

```text
Percent = max(existing.Percent, incomingEffectivePercent)
RemainingSeconds = max(existing.RemainingSeconds, incomingDurationSeconds)
```

### 7. Статусы

В первой версии поддерживается только один статус:

```text
SlowStatus
```

DoT, stun, knockback, shield, regen, burn, bleed и другие эффекты в `N5` не добавляются.

Универсальная статусная система пока не вводится.

### 8. Время эффектов

Все длительности эффектов измеряются в симуляционных секундах.

`GameSpeed` влияет на скорость накопления симуляционного времени в игровом цикле, но не меняет контракт статусов.

`SlowStatus.RemainingSeconds` уменьшается на `deltaSeconds`, переданный симуляцией.

## Последствия

- `N6 Simulation engine` получает однозначные правила урона, брони, замедления и летающих целей.
- Контент может управлять бронебойностью через `ArmorIgnorePercent`.
- Летающие цели можно будет балансировать через `TowerType.CanTargetFlying`.
- Статусная система остается минимальной и не расширяется до появления отдельных требований.
~~~

~~~docs\decisions\0003-simulation-engine-assumptions.cmake
# ADR 0003: Simulation engine assumptions

## Статус

Принято

## Контекст

Для реализации `N6 Simulation engine` недостаточно одних контрактов домена.
Нужно зафиксировать практические правила движения, спавна, атаки и утечки монстров.

## Решение

### 1. Модель атаки

Атака башни считается мгновенной:

```text
hitscan
```

Снаряды, время полета и промахи в первой версии не реализуются.

### 2. Выбор цели

Башня выбирает живого монстра:

```text
- находящегося в радиусе башни;
- которого башня может атаковать по правилам Flying;
- с максимальным PathProgress среди подходящих целей.
```

### 3. Спавн монстров

Монстры из волны спавнятся последовательно.

Интервал спавна:

```text
SpawnIntervalSeconds = 0.75
```

Значение является плейсхолдером и может быть отбалансировано на `N15`.

### 4. Утечка монстра

Когда монстр достигает конца пути:

```text
база получает MonsterLeakDamage = 1
монстр удаляется из симуляции
```

Значение является плейсхолдером.

### 5. Splash и Flying

Splash-урон поражает только тех монстров, которые являются допустимыми целями для башни.

Если:

```text
MonsterType.IsFlying == true
TowerType.CanTargetFlying == false
```

то такой монстр не получает урон от башни, включая splash.

### 6. GameSpeed

`GameSpeed` не изменяет контракты симуляции.

Внешний игровой цикл масштабирует время:

```text
accumulator += realDeltaTime * speedMultiplier
while accumulator >= fixedDeltaTime:
    simulation.Update(fixedDeltaTime)
    accumulator -= fixedDeltaTime
~~~

~~~src\Td.Core\Domain\Common\Point2D.cs
using System;
using System.Globalization;


/// <summary>
/// Точка в логических координатах игрового поля.
/// Начало координат — левый верхний угол.
/// X увеличивается вправо, Y увеличивается вниз.
/// </summary>
public readonly record struct Point2D(double X, double Y)
{
    /// <summary>
    /// Точка (0, 0).
    /// </summary>
    public static Point2D Zero => new(0, 0);

    /// <summary>
    /// Расстояние до другой точки.
    /// </summary>
    public double DistanceTo(Point2D other)
    {
        double dx = X - other.X;
        double dy = Y - other.Y;

        return Math.Sqrt(dx * dx + dy * dy);
    }

    /// <summary>
    /// Квадрат расстояния до другой точки.
    /// Используется там, где не нужен Math.Sqrt.
    /// </summary>
    public double DistanceSquaredTo(Point2D other)
    {
        double dx = X - other.X;
        double dy = Y - other.Y;

        return dx * dx + dy * dy;
    }

    /// <summary>
    /// Возвращает новую точку, смещенную относительно текущей.
    /// </summary>
    public Point2D Offset(double dx, double dy)
    {
        return new Point2D(X + dx, Y + dy);
    }

    public static Point2D operator +(Point2D left, Point2D right)
    {
        return new Point2D(left.X + right.X, left.Y + right.Y);
    }

    public static Point2D operator -(Point2D left, Point2D right)
    {
        return new Point2D(left.X - right.X, left.Y - right.Y);
    }

    public static Point2D operator *(Point2D point, double scale)
    {
        return new Point2D(point.X * scale, point.Y * scale);
    }

    public static Point2D operator /(Point2D point, double scale)
    {
        return new Point2D(point.X / scale, point.Y / scale);
    }

    public override string ToString()
    {
        return string.Format(
            CultureInfo.InvariantCulture,
            "({0}, {1})",
            X,
            Y);
    }
}

~~~src\Td.Core\Domain\Game\GameState.cs


/// <summary>
/// Корень агрегата игрового состояния. 
/// Инкапсулирует все мутации и гарантирует соблюдение бизнес-инвариантов.
/// </summary>
public sealed class GameState
{
    private readonly List<TowerState> _towers = new();
    private readonly List<MonsterState> _monsters = new();

    public required MapDefinition Map { get; init; }
    
    // TotalWaves не должен меняться в процессе матча
    public required int TotalWaves { get; init; } 

    public GamePhase Phase { get; private set; } = GamePhase.MainMenu;
    public GameSpeed Speed { get; set; } = GameSpeed.X1;
    
    public int Gold { get; private set; }
    public int Lives { get; private set; } = MechanicsLimits.BaseLives;
    
    public int CurrentWave { get; private set; }

    // Read-only view для предотвращения внешней мутации
    public IReadOnlyList<TowerState> Towers => _towers;
    public IReadOnlyList<MonsterState> Monsters => _monsters;

    // --- Явные триггеры и мутаторы состояния ---

	public void StartGame()
	{
		if (Phase is not (GamePhase.MainMenu or GamePhase.MapSelect))
			throw new InvalidOperationException($"Cannot start game from phase {Phase}.");

		_towers.Clear();
		_monsters.Clear();

		Gold = EconomyContent.StartingGold;
		Lives = MechanicsLimits.BaseLives;
		CurrentWave = 0;
		Phase = GamePhase.Playing;
	}

    public void PauseGame()
    {
        if (Phase != GamePhase.Playing) return;
        Phase = GamePhase.Paused;
    }

    public void ResumeGame()
    {
        if (Phase != GamePhase.Paused) return;
        Phase = GamePhase.Playing;
    }

    public void StartNextWave()
    {
        if (Phase != GamePhase.Playing)
            throw new InvalidOperationException("Cannot start wave outside of Playing phase.");
        if (CurrentWave >= TotalWaves)
            throw new InvalidOperationException("All waves have already been spawned.");
            
        CurrentWave++;
        EvaluateVictoryCondition();
    }

    public void AddTower(TowerState tower)
    {
        if (Phase != GamePhase.Playing)
            throw new InvalidOperationException("Cannot add towers outside of Playing phase.");
        
        _towers.Add(tower);
    }

    public void RemoveTower(TowerState tower)
    {
        _towers.Remove(tower);
    }

    public void AddMonster(MonsterState monster)
    {
        if (Phase != GamePhase.Playing)
            throw new InvalidOperationException("Cannot spawn monsters outside of Playing phase.");
        
        _monsters.Add(monster);
    }

    public void RemoveMonster(MonsterState monster)
    {
        _monsters.Remove(monster);
        EvaluateVictoryCondition();
    }

    public void ApplyBaseDamage(int damage)
    {
        if (damage <= 0) return;
        if (Phase != GamePhase.Playing) return;

        Lives -= damage;
        if (Lives <= 0)
        {
            Lives = 0;
            Phase = GamePhase.Defeat;
        }
    }

    public void AddGold(int amount)
    {
        if (amount < 0) throw new ArgumentException("Gold amount cannot be negative.");
        Gold += amount;
    }

    public void SpendGold(int amount)
    {
        if (amount < 0) throw new ArgumentException("Amount cannot be negative.");
        if (Gold < amount) throw new InvalidOperationException("Insufficient gold.");
        
        Gold -= amount;
    }

    // --- Приватные методы оценки инвариантов ---

    private void EvaluateVictoryCondition()
    {
        if (Phase != GamePhase.Playing) return;

        bool allWavesSpawned = CurrentWave >= TotalWaves;
        // Проверяем, что все монстры либо удалены, либо мертвы (защита от гонок с очисткой списка)
        bool allMonstersDefeated = _monsters.Count == 0 || !_monsters.Any(m => m.IsAlive);

        if (allWavesSpawned && allMonstersDefeated)
        {
            Phase = GamePhase.Victory;
        }
    }
}

~~~src\Td.Core\Domain\Maps\MapPlacementValidator.cs
using System;
using System.Collections.Generic;




public sealed class MapPlacementValidator : IPlacementValidator
{
    private readonly IPathGeometry _pathGeometry;

    public MapPlacementValidator(IPathGeometry pathGeometry)
    {
        _pathGeometry = pathGeometry ?? throw new ArgumentNullException(nameof(pathGeometry));
    }

    public bool CanPlaceTower(
        MapDefinition map,
        Point2D position,
        TowerType towerType,
        IReadOnlyCollection<TowerState> existingTowers)
    {
        if (map is null)
        {
            return false;
        }

        if (towerType is null)
        {
            return false;
        }

        if (existingTowers is null)
        {
            return false;
        }

        if (map.Path is null || map.Path.Count < 2)
        {
            return false;
        }

        double towerRadius = towerType.FootprintRadius;

        if (towerRadius <= 0)
        {
            return false;
        }

        if (!IsInsideMap(map, position, towerRadius))
        {
            return false;
        }

        if (!IsAwayFromPath(map, position, towerRadius))
        {
            return false;
        }

        if (!IsNotOverlappingExistingTowers(position, towerRadius, existingTowers))
        {
            return false;
        }

        return true;
    }

    private static bool IsInsideMap(
        MapDefinition map,
        Point2D position,
        double towerRadius)
    {
        return
            position.X >= towerRadius &&
            position.X <= map.Width - towerRadius &&
            position.Y >= towerRadius &&
            position.Y <= map.Height - towerRadius;
    }

    private bool IsAwayFromPath(
        MapDefinition map,
        Point2D position,
        double towerRadius)
    {
        double distanceToPath = _pathGeometry.GetDistanceToPath(map.Path, position);

        double requiredDistance = map.PathBufferRadius + towerRadius;

        return distanceToPath >= requiredDistance;
    }

    private static bool IsNotOverlappingExistingTowers(
        Point2D position,
        double towerRadius,
        IReadOnlyCollection<TowerState> existingTowers)
    {
        foreach (TowerState tower in existingTowers)
        {
            if (tower is null)
            {
                continue;
            }

            if (tower.Type is null)
            {
                continue;
            }

            double otherRadius = tower.Type.FootprintRadius;

            double requiredDistance = towerRadius + otherRadius;

            double distanceSquared = position.DistanceSquaredTo(tower.Position);

            if (distanceSquared < requiredDistance * requiredDistance)
            {
                return false;
            }
        }

        return true;
    }
}

~~~src\Td.Core\Domain\Maps\PathGeometry.cs
using System;
using System.Collections.Generic;

/// <summary>
/// Базовая реализация геометрии пути на основе ломаной линии.
/// </summary>
public sealed class PathGeometry : IPathGeometry
{
    public double GetLength(IReadOnlyList<Point2D> path)
    {
        if (path is null || path.Count < 2)
        {
            return 0.0;
        }

        double length = 0.0;

        for (int i = 1; i < path.Count; i++)
        {
            length += path[i - 1].DistanceTo(path[i]);
        }

        return length;
    }

    public Point2D GetPointAtDistance(
        IReadOnlyList<Point2D> path,
        double distance)
    {
        if (path is null || path.Count == 0)
        {
            return Point2D.Zero;
        }

        if (path.Count == 1)
        {
            return path[0];
        }

        if (distance <= 0.0)
        {
            return path[0];
        }

        double remaining = distance;

        for (int i = 1; i < path.Count; i++)
        {
            Point2D segmentStart = path[i - 1];
            Point2D segmentEnd = path[i];
            double segmentLength = segmentStart.DistanceTo(segmentEnd);

            if (remaining <= segmentLength)
            {
                if (segmentLength == 0.0)
                {
                    return segmentStart;
                }

                double t = remaining / segmentLength;
                return new Point2D(
                    segmentStart.X + (segmentEnd.X - segmentStart.X) * t,
                    segmentStart.Y + (segmentEnd.Y - segmentStart.Y) * t);
            }

            remaining -= segmentLength;
        }

        return path[^1];
    }

    public double GetDistanceToPath(
        IReadOnlyList<Point2D> path,
        Point2D point)
    {
        if (path is null || path.Count == 0)
        {
            return double.MaxValue;
        }

        if (path.Count == 1)
        {
            return point.DistanceTo(path[0]);
        }

        double minDistance = double.MaxValue;

        for (int i = 1; i < path.Count; i++)
        {
            double distance = DistancePointToSegment(point, path[i - 1], path[i]);
            if (distance < minDistance)
            {
                minDistance = distance;
            }
        }

        return minDistance;
    }

    private static double DistancePointToSegment(
        Point2D point,
        Point2D segmentStart,
        Point2D segmentEnd)
    {
        double vx = segmentEnd.X - segmentStart.X;
        double vy = segmentEnd.Y - segmentStart.Y;

        double wx = point.X - segmentStart.X;
        double wy = point.Y - segmentStart.Y;

        double lengthSquared = vx * vx + vy * vy;

        if (lengthSquared == 0.0)
        {
            return point.DistanceTo(segmentStart);
        }

        double projection = (wx * vx + wy * vy) / lengthSquared;
        projection = Math.Clamp(projection, 0.0, 1.0);

        Point2D closest = new Point2D(
            segmentStart.X + vx * projection,
            segmentStart.Y + vy * projection);

        return point.DistanceTo(closest);
    }
}

/// <summary>
/// Состояние монстра. Инкапсулирует инварианты здоровья, прогресса по пути и статусов.
/// </summary>
public sealed class MonsterState
{
    private double _pathProgress;
    private double _currentHp;

    public required Guid Id { get; init; }
    public required MonsterType Type { get; init; }
    
    /// <summary>
    /// Текущее здоровье. Жестко ограничено диапазоном [0, Type.MaxHp] для предотвращения оверхила.
    /// </summary>
    public double CurrentHp 
    { 
        get => _currentHp; 
        set => _currentHp = Math.Clamp(value, 0.0, Type.MaxHp); 
    }

    public required Point2D Position { get; set; }

    /// <summary>
    /// Нормализованный прогресс монстра по пути от 0.0 (спавн) до 1.0 (финиш/база).
    /// </summary>
    public double PathProgress 
    { 
        get => _pathProgress; 
        set => _pathProgress = Math.Clamp(value, 0.0, 1.0); 
    }

    public SlowStatus? Slow { get; private set; }

    public bool IsAlive => CurrentHp > 0;

    /// <summary>
    /// Применяет эффект замедления. 
    /// Учитывает сопротивление монстра и абсолютный лимит игры (MaxSlowPercent).
    /// Правило стакинга: берется максимальный процент, таймер обновляется до максимального значения.
    /// </summary>
	public void ApplySlow(double basePercent, double durationSeconds)
	{
		if (basePercent <= 0 || durationSeconds <= 0) return;

		double clampedBasePercent = Math.Clamp(basePercent, 0.0, 1.0);
		double clampedSlowResistance = Math.Clamp(Type.SlowResistance, 0.0, 1.0);

		// 1. Учет сопротивления (линейное снижение)
		double effectivePercent = clampedBasePercent * (1.0 - clampedSlowResistance);

		// 2. Применение абсолютного лимита игры (потолок)
		effectivePercent = Math.Min(effectivePercent, MechanicsLimits.MaxSlowPercent);

		// 3. Стакинг (Refresh & Max)
		if (Slow == null)
		{
			Slow = new SlowStatus
			{
				Percent = effectivePercent,
				RemainingSeconds = durationSeconds
			};
		}
		else
		{
			Slow = Slow with
			{
				Percent = Math.Max(Slow.Percent, effectivePercent),
				RemainingSeconds = Math.Max(Slow.RemainingSeconds, durationSeconds)
			};
		}
	}
	
	/// <summary>
	/// Применяет урон к монстру. Здоровье автоматически ограничивается диапазоном [0, MaxHp].
	/// </summary>
	public void ApplyDamage(int damage)
	{
		if (damage <= 0) return;

		CurrentHp -= damage;
	}

    /// <summary>
    /// Обновляет таймер замедления на шаг симуляции. Сбрасывает эффект при истечении.
    /// </summary>
    public void TickSlow(double deltaSeconds)
    {
        if (Slow == null) return;

        double newTime = Slow.RemainingSeconds - deltaSeconds;
        if (newTime <= 0)
        {
            Slow = null;
        }
        else
        {
            Slow = Slow with { RemainingSeconds = newTime };
        }
    }
}

/// <summary>
/// Состояние башни. Инкапсулирует инварианты уровня, экономики и доступа к конфигурации.
/// </summary>
public sealed class TowerState
{
    private int _level = MechanicsLimits.MinUpgradeLevel;

    public required Guid Id { get; init; }
    public required TowerType Type { get; init; }
    
    // Позиция башни фиксируется при установке. 
    // Если в игре не предусмотрено перемещение башен, рекомендуется заменить set на init.
    public required Point2D Position { get; set; }

	/// <summary>
	/// Оставшееся время до следующего выстрела.
	/// </summary>
	public double CooldownRemainingSeconds { get; private set; }

	/// <summary>
	/// Уменьшает кулдаун на шаг симуляции.
	/// </summary>
	public void TickCooldown(double deltaSeconds)
	{
		if (deltaSeconds <= 0) return;
		if (CooldownRemainingSeconds <= 0) return;

		CooldownRemainingSeconds = Math.Max(0.0, CooldownRemainingSeconds - deltaSeconds);
	}

	/// <summary>
	/// Устанавливает кулдаун после выстрела.
	/// </summary>
	public void SetCooldown(double cooldownSeconds)
	{
		if (cooldownSeconds < 0)
		{
			throw new ArgumentException("Cooldown cannot be negative.");
		}

		CooldownRemainingSeconds = cooldownSeconds;
	}

    /// <summary>
    /// Текущий уровень башни. 
    /// Жестко ограничен глобальными лимитами и фактическим количеством уровней в TowerType.
    /// </summary>
    public int Level
    {
        get => _level;
        private set
        {
            int maxAllowedLevel = Math.Min(MechanicsLimits.MaxUpgradeLevel, Type.Levels.Count);
            if (value < MechanicsLimits.MinUpgradeLevel || value > maxAllowedLevel)
            {
                throw new ArgumentOutOfRangeException(
                    nameof(value), 
                    $"Level must be between {MechanicsLimits.MinUpgradeLevel} and {maxAllowedLevel}.");
            }
            _level = value;
        }
    }

    /// <summary>
    /// Суммарное золото, вложенное в башню (стоимость покупки + сумма апгрейдов).
    /// Используется для расчета стоимости продажи.
    /// </summary>
    public int InvestedGold { get; private set; }

    /// <summary>
    /// Быстрый доступ к конфигурации текущего уровня (урон, радиус, кулдаун и т.д.).
    /// </summary>
    public TowerLevelDefinition CurrentLevelDefinition => Type.Levels[Level - 1];

    public bool CanUpgrade => Level < Math.Min(MechanicsLimits.MaxUpgradeLevel, Type.Levels.Count);

    /// <summary>
    /// Инициализирует базовую стоимость при покупке башни.
    /// </summary>
    public void InitializeInvestment(int baseCost)
    {
        if (InvestedGold != 0) 
            throw new InvalidOperationException("Investment has already been initialized.");
        if (baseCost < 0) 
            throw new ArgumentException("Base cost cannot be negative.");
            
        InvestedGold = baseCost;
    }

    /// <summary>
    /// Рассчитывает стоимость следующего апгрейда.
    /// </summary>
    public int GetUpgradeCost()
    {
        if (!CanUpgrade) return 0;
        // Level - 1 это текущий уровень (индекс). Level это индекс следующего уровня.
        return Type.Levels[Level].UpgradeCost; 
    }

    /// <summary>
    /// Применяет апгрейд башни. 
    /// Примечание: Проверка наличия золота у игрока должна выполняться в Domain Service до вызова этого метода.
    /// </summary>
    public void Upgrade()
    {
        if (!CanUpgrade)
            throw new InvalidOperationException("Tower is already at maximum level.");

        InvestedGold += GetUpgradeCost();
        Level++;
    }
}

~~~src\Td.Core\Domain\Waves\RandomWaveGenerator.cs
using System;
using System.Collections.Generic;
using System.Linq;

/// <summary>
/// Генератор случайных волн.
/// Правила генерации зафиксированы в ADR 0004.
/// Баланс является плейсхолдером до этапа N15.
/// </summary>
public sealed class RandomWaveGenerator : IRandomWaveGenerator
{
    private const int SafetyIterationLimit = 10_000;

    private readonly IReadOnlyList<MonsterType> _monsterCatalog;

    public RandomWaveGenerator(IReadOnlyList<MonsterType> monsterCatalog)
    {
        ArgumentNullException.ThrowIfNull(monsterCatalog);

        if (monsterCatalog.Count == 0)
        {
            throw new ArgumentException("Monster catalog cannot be empty.", nameof(monsterCatalog));
        }

        _monsterCatalog = monsterCatalog;
    }

    public int RollTotalWaveCount(Random random)
    {
        ArgumentNullException.ThrowIfNull(random);

        return random.Next(
            WaveGenerationRules.MinWaveCount,
            WaveGenerationRules.MaxWaveCount + 1);
    }

    public WaveDefinition GenerateWave(int waveNumber, int totalWaves, Random random)
    {
        ArgumentNullException.ThrowIfNull(random);
        ValidateWaveNumbers(waveNumber, totalWaves);

        int maxTier = GetMaxAllowedTier(waveNumber, totalWaves);
        int budget = GetWaveBudget(waveNumber);
        int maxMonsters = Math.Max(1, WaveGenerationRules.MaxAliveMonsters);

        List<MonsterType> allowed = _monsterCatalog
            .Where(monster => monster.Tier >= WaveGenerationRules.MinMonsterTier)
            .Where(monster => monster.Tier <= maxTier)
            .OrderBy(monster => monster.Id, StringComparer.Ordinal)
            .ToList();

        if (allowed.Count == 0)
        {
            throw new InvalidOperationException(
                $"No monsters are available for wave {waveNumber}/{totalWaves} with max tier {maxTier}.");
        }

        Dictionary<string, int> counts = new(StringComparer.Ordinal);
        int totalMonsters = 0;

        TryAddGuaranteedMaxTierMonster(
            allowed,
            maxTier,
            random,
            ref budget,
            ref totalMonsters,
            maxMonsters,
            counts);

        int minCost = allowed.Min(MonsterCost);
        int guard = 0;

        while (budget >= minCost && totalMonsters < maxMonsters && guard < SafetyIterationLimit)
        {
            guard++;

            MonsterType candidate = allowed[random.Next(allowed.Count)];
            int cost = MonsterCost(candidate);

            if (cost > budget)
            {
                continue;
            }

            AddMonster(counts, candidate.Id);
            budget -= cost;
            totalMonsters++;
        }

        if (totalMonsters == 0)
        {
            MonsterType cheapest = allowed
                .OrderBy(monster => MonsterCost(monster))
                .ThenBy(monster => monster.Id, StringComparer.Ordinal)
                .First();

            AddMonster(counts, cheapest.Id);
            totalMonsters = 1;
        }

        IReadOnlyList<WaveEntry> entries = counts
            .OrderBy(pair => pair.Key, StringComparer.Ordinal)
            .Select(pair => new WaveEntry
            {
                MonsterTypeId = pair.Key,
                Count = pair.Value
            })
            .ToList();

        return new WaveDefinition
        {
            WaveNumber = waveNumber,
            TotalWaves = totalWaves,
            Entries = entries
        };
    }

    public IReadOnlyList<WaveDefinition> GenerateAllWaves(Random random)
    {
        ArgumentNullException.ThrowIfNull(random);

        int totalWaves = RollTotalWaveCount(random);
        List<WaveDefinition> waves = new(totalWaves);

        for (int waveNumber = 1; waveNumber <= totalWaves; waveNumber++)
        {
            waves.Add(GenerateWave(waveNumber, totalWaves, random));
        }

        return waves;
    }

    private static void ValidateWaveNumbers(int waveNumber, int totalWaves)
    {
        if (totalWaves < 1)
        {
            throw new ArgumentOutOfRangeException(
                nameof(totalWaves),
                "Total waves must be positive.");
        }

        if (waveNumber < 1 || waveNumber > totalWaves)
        {
            throw new ArgumentOutOfRangeException(
                nameof(waveNumber),
                "Wave number must be between 1 and total waves.");
        }
    }

    private static int GetWaveBudget(int waveNumber)
    {
        return WaveGenerationRules.BaseWaveBudget +
               (waveNumber - 1) * WaveGenerationRules.WaveBudgetGrowth;
    }

    private static int GetMaxAllowedTier(int waveNumber, int totalWaves)
    {
        int tierSpan = WaveGenerationRules.MaxMonsterTier - WaveGenerationRules.MinMonsterTier;

        if (tierSpan <= 0)
        {
            return WaveGenerationRules.MinMonsterTier;
        }

        double progress = (waveNumber - 1) / (double)Math.Max(1, totalWaves - 1);
        int tier = WaveGenerationRules.MinMonsterTier + (int)Math.Floor(progress * tierSpan);

        return Math.Clamp(
            tier,
            WaveGenerationRules.MinMonsterTier,
            WaveGenerationRules.MaxMonsterTier);
    }

    private static int MonsterCost(MonsterType monster)
    {
        return Math.Max(1, monster.Tier);
    }

    private static void TryAddGuaranteedMaxTierMonster(
        IReadOnlyList<MonsterType> allowed,
        int maxTier,
        Random random,
        ref int budget,
        ref int totalMonsters,
        int maxMonsters,
        IDictionary<string, int> counts)
    {
        if (totalMonsters >= maxMonsters)
        {
            return;
        }

        List<MonsterType> candidates = allowed
            .Where(monster => monster.Tier == maxTier)
            .ToList();

        if (candidates.Count == 0)
        {
            return;
        }

        MonsterType monster = candidates[random.Next(candidates.Count)];
        int cost = MonsterCost(monster);

        if (cost > budget)
        {
            return;
        }

        AddMonster(counts, monster.Id);
        budget -= cost;
        totalMonsters++;
    }

    private static void AddMonster(IDictionary<string, int> counts, string monsterTypeId)
    {
        counts[monsterTypeId] = counts.TryGetValue(monsterTypeId, out int existing)
            ? existing + 1
            : 1;
    }
}

using System;

/// <summary>
/// Реализация калькулятора урона по модели Flat Reduction.
/// </summary>
public sealed class DamageCalculator : IDamageCalculator
{
    public int CalculateDamage(TowerLevelDefinition towerLevel, MonsterType monsterType)
    {
        ArgumentNullException.ThrowIfNull(towerLevel);
        ArgumentNullException.ThrowIfNull(monsterType);

        double armorIgnorePercent = Math.Clamp(towerLevel.ArmorIgnorePercent, 0.0, 1.0);

        int effectiveArmor = (int)Math.Floor(monsterType.Armor * (1.0 - armorIgnorePercent));

        return Math.Max(1, towerLevel.Damage - effectiveArmor);
    }
}

~~~src\Td.Core\Simulation\GameSimulationEngine.cs
using System;
using System.Collections.Generic;
using System.Linq;

/// <summary>
/// Базовый симуляционный движок:
/// спавн монстров, движение, замедление, атака башен, урон, смерть, утечка.
/// </summary>
public sealed class GameSimulationEngine : ISimulationEngine
{
    private const double ComparisonEpsilon = 0.0001;

    private readonly IPathGeometry _pathGeometry;
    private readonly IDamageCalculator _damageCalculator;
    private readonly IReadOnlyList<WaveDefinition> _waves;
    private readonly Dictionary<string, MonsterType> _monsterCatalogById;
    private readonly Queue<SpawnRequest> _spawnQueue = new();

    private double _spawnTimer;

    public GameSimulationEngine(
        IPathGeometry pathGeometry,
        IDamageCalculator damageCalculator,
        IReadOnlyList<MonsterType> monsterCatalog,
        IReadOnlyList<WaveDefinition> waves)
    {
        _pathGeometry = pathGeometry ?? throw new ArgumentNullException(nameof(pathGeometry));
        _damageCalculator = damageCalculator ?? throw new ArgumentNullException(nameof(damageCalculator));
        _waves = waves ?? throw new ArgumentNullException(nameof(waves));

        if (monsterCatalog is null)
        {
            throw new ArgumentNullException(nameof(monsterCatalog));
        }

        _monsterCatalogById = monsterCatalog.ToDictionary(monster => monster.Id, monster => monster);
    }

    public void StartNextWave(GameState state)
    {
        ArgumentNullException.ThrowIfNull(state);

        if (state.Phase != GamePhase.Playing)
        {
            return;
        }

        if (_spawnQueue.Count > 0 || state.Monsters.Any(monster => monster.IsAlive))
        {
            return;
        }

        int maxWaves = Math.Min(state.TotalWaves, _waves.Count);

        if (state.CurrentWave >= maxWaves)
        {
            return;
        }

        state.StartNextWave();

        WaveDefinition wave = _waves[state.CurrentWave - 1];
        EnqueueWave(wave);
    }

    public void Update(GameState state, double deltaSeconds)
    {
        ArgumentNullException.ThrowIfNull(state);

        if (state.Phase != GamePhase.Playing)
        {
            return;
        }

        if (deltaSeconds <= 0)
        {
            return;
        }

        ProcessSpawns(state, deltaSeconds);

        UpdateMonsters(state, deltaSeconds);

        if (state.Phase != GamePhase.Playing)
        {
            return;
        }

        UpdateTowers(state, deltaSeconds);
    }

    private void EnqueueWave(WaveDefinition wave)
    {
        foreach (WaveEntry entry in wave.Entries)
        {
            int count = Math.Max(0, entry.Count);

            for (int i = 0; i < count; i++)
            {
                _spawnQueue.Enqueue(new SpawnRequest(entry.MonsterTypeId));
            }
        }

        _spawnTimer = 0.0;
    }

    private void ProcessSpawns(GameState state, double deltaSeconds)
    {
        if (_spawnQueue.Count == 0)
        {
            _spawnTimer = 0.0;
            return;
        }

        _spawnTimer -= deltaSeconds;

        double interval = Math.Max(0.01, WaveGenerationRules.SpawnIntervalSeconds);

        while (_spawnQueue.Count > 0 && _spawnTimer <= 0.0)
        {
            SpawnRequest request = _spawnQueue.Dequeue();

            if (_monsterCatalogById.TryGetValue(request.MonsterTypeId, out MonsterType? monsterType))
            {
                state.AddMonster(CreateMonster(state, monsterType));
            }

            _spawnTimer += interval;
        }
    }

    private static MonsterState CreateMonster(GameState state, MonsterType type)
    {
        Point2D startPosition = state.Map.Path.Count > 0
            ? state.Map.Path[0]
            : Point2D.Zero;

        return new MonsterState
        {
            Id = Guid.NewGuid(),
            Type = type,
            Position = startPosition,
            CurrentHp = type.MaxHp,
            PathProgress = 0.0
        };
    }

    private void UpdateMonsters(GameState state, double deltaSeconds)
    {
        IReadOnlyList<Point2D> path = state.Map.Path;
        double pathLength = _pathGeometry.GetLength(path);

        List<MonsterState> leaked = new();

        foreach (MonsterState monster in state.Monsters)
        {
            if (!monster.IsAlive)
            {
                continue;
            }

            monster.TickSlow(deltaSeconds);

            double slowPercent = monster.Slow?.Percent ?? 0.0;
            double speedFactor = Math.Clamp(1.0 - slowPercent, 0.0, 1.0);

            double moveDistance = monster.Type.Speed * speedFactor * deltaSeconds;

            if (pathLength <= 0.0)
            {
                monster.PathProgress = 1.0;
            }
            else
            {
                monster.PathProgress += moveDistance / pathLength;
            }

            if (monster.PathProgress >= 1.0)
            {
                monster.Position = path.Count > 0 ? path[^1] : Point2D.Zero;
                leaked.Add(monster);
            }
            else
            {
                monster.Position = _pathGeometry.GetPointAtDistance(
                    path,
                    monster.PathProgress * pathLength);
            }
        }

        foreach (MonsterState monster in leaked)
        {
            state.ApplyBaseDamage(EconomyContent.MonsterLeakDamage);
            state.RemoveMonster(monster);
        }
    }

    private void UpdateTowers(GameState state, double deltaSeconds)
    {
        HashSet<MonsterState> killed = new();

        foreach (TowerState tower in state.Towers)
        {
            tower.TickCooldown(deltaSeconds);

            if (tower.CooldownRemainingSeconds > 0.0)
            {
                continue;
            }

            TowerLevelDefinition level = tower.CurrentLevelDefinition;

            MonsterState? target = SelectTarget(state, tower, level.Range);

            if (target is null)
            {
                continue;
            }

            tower.SetCooldown(level.CooldownSeconds);

            Point2D impactPoint = target.Position;

            foreach (MonsterState victim in GetDamageTargets(state, tower, level, impactPoint, target))
            {
                if (!victim.IsAlive)
                {
                    continue;
                }

                int damage = _damageCalculator.CalculateDamage(level, victim.Type);
                victim.ApplyDamage(damage);

                if (!victim.IsAlive)
                {
                    killed.Add(victim);
                }
            }
        }

        foreach (MonsterState monster in killed)
        {
            state.AddGold(monster.Type.GoldReward);
            state.RemoveMonster(monster);
        }
    }

    private static MonsterState? SelectTarget(
        GameState state,
        TowerState tower,
        double range)
    {
        MonsterState? bestTarget = null;

        foreach (MonsterState monster in state.Monsters)
        {
            if (!monster.IsAlive)
            {
                continue;
            }

            if (monster.Type.IsFlying && !tower.Type.CanTargetFlying)
            {
                continue;
            }

            double distance = tower.Position.DistanceTo(monster.Position);

            if (distance > range + ComparisonEpsilon)
            {
                continue;
            }

            if (bestTarget is null || monster.PathProgress > bestTarget.PathProgress)
            {
                bestTarget = monster;
            }
        }

        return bestTarget;
    }

    private static IReadOnlyList<MonsterState> GetDamageTargets(
        GameState state,
        TowerState tower,
        TowerLevelDefinition level,
        Point2D impactPoint,
        MonsterState primaryTarget)
    {
        List<MonsterState> targets = new();

        if (level.SplashRadius <= 0.0)
        {
            targets.Add(primaryTarget);
            return targets;
        }

        foreach (MonsterState monster in state.Monsters)
        {
            if (!monster.IsAlive)
            {
                continue;
            }

            if (monster.Type.IsFlying && !tower.Type.CanTargetFlying)
            {
                continue;
            }

            double distance = monster.Position.DistanceTo(impactPoint);

            if (distance <= level.SplashRadius + ComparisonEpsilon)
            {
                targets.Add(monster);
            }
        }

        return targets;
    }

    private sealed record SpawnRequest(string MonsterTypeId);
}
